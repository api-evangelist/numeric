# Numeric

> Numeric is an AI close-automation platform that unifies close management, reporting, and cash for complex accounting teams (customers include Brex, Plaid, and Stash). Its programmable surface is an OAuth-protected Model Context Protocol (MCP) server plus a published library of Claude Agent Skills ("Numeric Toolkit") for automating month-end close, reconciliation, flux/variance analysis, and reporting.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Numeric public surface; Numeric does not publish its own /llms.txt.

## Agent / MCP surface
- [MCP server](https://api.numeric.io/mcp): OAuth 2.0 bearer-protected streamable-HTTP MCP endpoint.
- [Claude Skills Library](https://www.numeric.io/claude-skills-library): 15 published agent skills across journals, audit, flux/variance, reporting, close, and reconciliation.
- [Accruals use case](https://www.numeric.io/mcp-use-cases/complete-accruals-task): example agent workflow.

## Authentication
- [Authorization server metadata (RFC 8414)](https://api.numeric.io/.well-known/oauth-authorization-server)
- [OpenID configuration](https://auth.numeric.io/.well-known/openid-configuration)
- [Protected resource metadata (RFC 9728)](https://api.numeric.io/.well-known/oauth-protected-resource)
- OAuth 2.0 / OIDC via https://auth.numeric.io — scopes: openid, profile, email, offline_access; grants: authorization_code, refresh_token, device_code, client_credentials; PKCE S256; dynamic client registration.
